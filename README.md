# 789 Trip Calculator

4-20 mA trip calculator for a Fluke 789 on mA SOURCE with the loop kept closed.
Enter the range and trip, pick going up or going down, and it gives the mA the
PLC needs and what to set the 789 to.

Installable web app that works with no signal after the first open.

Install on Android: open the page in Chrome, menu (three dots), Add to home screen, Install.
